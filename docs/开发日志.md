# 开发日志

## v1.0.0(2026-09-09)正式版:iPad 日程时间线

- 深色主题(默认,`color-scheme: dark`,主题色 #5b8cff)
- 布局:iPad 双栏(左 350px 面板 + 右侧时间线;≤700px 视口时上下堆叠兜底)
- 左栏:顶部「今天/明天」切换;表单(任务名/备注/开始时间/结束时间,结束早于开始自动 +1h 并提示);当天统计(项数/总时长)
- 右栏:0:00–24:00 日时间线(每小时 52px,整点实线/半点虚线),任务块按时间定位,重叠任务自动分列;仅今天显示红色「现在」线(每分钟刷新);空状态提示
- 交互:点击任务块 → 浮层(查看详情/删除/编辑回填表单);编辑态保存覆盖原任务
- 数据:localStorage(`quick-schedule-items-v1`),任务存 `{day:'YYYY-MM-DD', startMin, endMin}` 分钟制,支持跨午夜(显示截断到 24:00)
- 说明:仅在 iPad 上使用(Safari 全屏),不考虑手机优化

## v0.1.0(2026-09-09)第一版:验证界面

- 按《iOS 小工具开发流程.md》走通全流程:单文件 PWA → 本地验证 → GitHub Pages 发布
- 界面:`app/index.html`(HTML+CSS+JS 内嵌),功能:
  - 快速添加日程(文本 + 时间,含"现在/半小时后/今晚8点/明天早上"快捷时间)
  - 列表按时间排序,显示今天/明天/周几,过期红色提示
  - 勾选完成、× 删除、"全部/未完成/已完成"筛选
  - 顶部今日日期与统计(全部/今天/已完成)
  - 数据存 localStorage(本机,无后端)
- 图标:lucide 日历图标(蓝底白标),由 lucide-static SVG + sharp 渲染生成 180/512 PNG
- 依赖:lucide 0.454.0(本地化到 `app/vendor/lucide.min.js`,不依赖 CDN)
- 托管:GitHub Pages,仓库 quick-schedule(公开),Pages 源目录 `app`
- 发布方式:GitHub Actions(push 到 main 自动部署)——原因:GitHub Pages 源只支持根目录或 `docs/`,不支持自定义 `app/` 目录,故用 Actions 上传 artifact 发布
- 线上地址:https://night-system.github.io/quick-schedule/
- 运行流程:改 `app/` 代码 → git push → Actions 自动发布(约 1 分钟)→ 手机打开即为新版
- 本地开发:`node tools/serve.mjs 8080`(本机无 python,serve.mjs 是 node 版静态服务器)
- 遗留:手机 Safari 打开 → 添加到主屏幕 → 真机验证安装效果
